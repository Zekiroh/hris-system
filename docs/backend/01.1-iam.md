# 01 – Identity & Access Management (IAM)

## Module Overview

The Identity & Access Management (IAM) module serves as the security foundation of the HRIS system.  
It handles authentication, authorization, user administration, and system audit logging.

This module was completed and stabilized before proceeding to Employee Core.

---

## Screens Covered

- Login
- User Management
- Access Management
- Activity Log Monitoring

---

## Core Responsibilities

### 1. Authentication (JWT-Based)
- Secure login endpoint
- Password validation using BCrypt
- JWT token generation
- Claims-based identity

### 2. Role-Based Access Control (RBAC)
- Roles:
  - Super Admin
  - Admin
  - User
- Permission matrix:
  - View
  - Create
  - Update
  - Archive
- Module-level enforcement

### 3. Permission Enforcement
- Custom `[PermissionAuthorize]` attribute
- Module + action-level authorization
- Claims-based evaluation

### 4. User Management
- Create user
- Update user
- Activate / Deactivate account
- Reset password
- Role assignment

### 5. Activity Logging
- Admin actions logged
- Employee-related actions logged
- Date filtering
- Export support (CSV)
